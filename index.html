Karmix Tech Internship — Project 5

CareConnect — Healthcare Appointment Booking App

A mobile appointment-booking experience focused on finding doctors, selecting suitable time slots, and confirming appointments clearly.

View case study

01 — USER RESEARCH

Understanding appointment needs

Users need trustworthy doctor information, available time slots, clear appointment details, and a simple booking process.

02 — USER PERSONA

Primary user

A student, working adult, or family member who wants to find an appropriate doctor and book an appointment without unnecessary complexity.

03 — USER FLOW

Find → Book → Confirm

Open app → Select specialty → Choose doctor → View profile → Select date/time → Enter details → Confirm appointment.

04 — WIREFRAMES

Low-fidelity structure

The wireframe stage establishes the hierarchy for Home, Doctor Search, Doctor Profile, Slot Selection, and Confirmation screens.

05 — HIGH-FIDELITY UI

Clear and reassuring interface

The interface prioritizes readable doctor information, appointment availability, clear confirmation states, and accessible navigation.

06 — DESIGN SYSTEM

Consistent components

Typography, buttons, cards, calendar/slot components, status indicators, forms, and navigation elements create a consistent experience.
